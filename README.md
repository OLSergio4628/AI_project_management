# AI_project_management
El estudiante analiza, selecciona e implementa modelos preentrenados de Hugging Face para un caso de uso definido, utilizando Google Colab con GPU como entorno de prototipado rápido. Durante la actividad, se identifican los componentes clave del ecosistema Hugging Face (Models, Datasets y Spaces), se establecen criterios técnicos y prácticos de selección y se implementan al menos tres modelos distintos, los cuales se comparan mediante métricas estándar, como accuracy, precision, recall y F1-score.

Asimismo, se evalúa el equilibrio entre precisión y eficiencia, se analiza el desempeño en relación con el contexto del problema y se documentan de forma clara los resultados, las decisiones técnicas y las condiciones de ejecución.

Finalmente, se justifica la selección del modelo más adecuado y se organiza un repositorio en GitHub que garantice la reproducibilidad, validación y mantenimiento del prototipo.

Identificar e implementar el modelo preentrenado más adecuado para un caso de uso específico.
